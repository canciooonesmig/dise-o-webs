# Design references

DESIGN.md files from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (commit `f696123`, MIT license — see `LICENSE`).

Each folder holds a `DESIGN.md` describing the visual language of a real website (colors, typography, spacing, components).

To use one for a project, copy it to the project root as `DESIGN.md` and ask the agent to build the UI following it, e.g.:

```sh
cp design-references/stripe/DESIGN.md ./DESIGN.md
```
